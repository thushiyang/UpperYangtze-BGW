# Basic model settings

| Setting | Study definition |
|---|---|
| Spatial structure | 68 subbasins; fixed 796-HRU scenario structure |
| Warm-up | 1980-1981 |
| Monthly streamflow calibration / validation | 1982-2010 / 2011-2020 |
| Historical / future result windows | 1982-2020 / 2021-2050 |
| Scarcity and water-use window | 2006-2020 |
| Baseline land use | 2015 CNLUCC |
| Meteorological forcing | Observed precipitation/temperature at 56 SWAT input stations; 271-station support network; other weather variables generated by SWAT |

Scenario definitions are in `config/`: 49 P-T perturbations (S25 reference), six prescribed land-use conversions and 24 six-GCM/four-SSP combinations. Crossing the latter two gives 144 matched climate-land-use cases. These are design tables, not the full daily forcing or spatial model inputs.

Calibration definitions, physical bounds, fitted adjustments and applied values are in Supplementary Tables S1-S3; streamflow evaluation is in Table S4. This deposit does not duplicate parameter tables or include additional sampling-range tables. Spatial inputs and climate-forcing evaluation are described in the article and Supplementary Figures S1-S3, S6-S7 and Table S5.

This is a basic settings summary, not an executable SWAT configuration. Full run-specific inputs and executable provenance are retained by the authors.
